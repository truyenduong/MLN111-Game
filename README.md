# THE MATRIX OF KNOWLEDGE

Web game giáo dục local về Triết học Mác - Lênin, xây dựng bằng React + Vite + TypeScript.

## Chạy local

Yêu cầu Node.js 18+ và npm:

```bash
npm install
npm run dev
```

Mở `http://localhost:5173`.

Toàn bộ câu hỏi và dữ liệu ôn tập nằm trong `src/data`. Tiến trình, điểm gần nhất và chặng đã hoàn thành được lưu bằng `localStorage`; không cần backend, database hay API.
